# WEST 26/27 가족 로드트립 일정표

비밀번호로 보호되는 정적 페이지입니다. GitHub Pages로 서비스합니다.

## 동작 방식

GitHub Pages에는 서버가 없어 서버측 로그인을 붙일 수 없습니다.
대신 **본문 HTML 전체를 AES-256-GCM으로 암호화**해 `index.html` 안에 넣어 두고,
브라우저에서 비밀번호를 입력하면 그 자리에서 복호화해 보여줍니다.

- 키 유도: PBKDF2-SHA256, 300,000회, 랜덤 salt 16B
- 암호화: AES-256-GCM (랜덤 IV 12B, 인증 태그로 위변조 감지)
- 비밀번호를 모르면 저장소 소스에는 암호문만 보입니다.

## 환율 자동 반영

예산표의 `적용 환율 · 1 USD` 는 페이지를 열 때 자동으로 채워집니다.

- 조회처: `open.er-api.com` (1차) → jsDelivr `@fawazahmed0/currency-api` (2차)
  둘 다 무료·키 불필요·CORS 허용이며 하루 1회 갱신됩니다.
- 브라우저에서 **하루 한 번만** 조회하고 localStorage에 캐시합니다.
- 두 API가 모두 실패하면 `build.mjs` 가 빌드 시점에 구워 넣은 폴백 환율을 씁니다.
- 사용자가 환율칸을 직접 고치면 자동 갱신이 멈추고 그 값이 유지됩니다.
  `자동으로` 버튼을 누르면 다시 자동 조회로 돌아갑니다.

환율은 은행 매매기준율이 아니라 시장 중간환율입니다. 현찰 환전 기준으로 잡으려면
직접 입력으로 1.5~2% 정도 올려 쓰세요.

## 내용 수정 후 다시 배포하기

1. 원본 일정표 HTML을 `source/trip.html` 로 덮어씁니다.
   (이 파일은 평문이므로 `.gitignore` 처리되어 있고, 저장소에 올라가지 않습니다.)
2. 다시 빌드합니다.

   ```bash
   TRIP_PASSWORD='현재-비밀번호' node build.mjs
   ```

   빌드할 때마다 폴백 환율도 최신으로 갱신됩니다. 네트워크가 없으면 `SKIP_FX=1` 를 붙이세요.

3. 커밋 & 푸시하면 1~2분 뒤 반영됩니다.

   ```bash
   git add index.html && git commit -m "일정표 갱신" && git push
   ```

## 비밀번호 바꾸기

`TRIP_PASSWORD` 를 새 값으로 넣고 2~3번을 다시 실행하면 됩니다.
기존 비밀번호로는 새 `index.html` 을 열 수 없습니다.

## 주의

- 저장소가 public이면 누구나 **암호문**을 내려받을 수 있습니다. 사전 대입 공격을
  막으려면 추측하기 쉬운 비밀번호(가족 이름, 생일, `west2627` 등)를 쓰지 마세요.
- 한 번 푸시한 비밀번호로 열리는 파일은 이후 비밀번호를 바꿔도 git 히스토리에 남습니다.
  유출이 의심되면 비밀번호 변경 + 히스토리 정리(또는 저장소 재생성)를 권합니다.
